# Cuero Artesanal | Admin (Maqueta)

Maqueta visual (sin backend ni lógica) para el control simple de ingresos, egresos y reportes de una microempresa de artículos de cuero hechos a mano.

## Qué incluye
- Navegación lateral: Inicio, Ingresos, Egresos, Reportes.
- Páginas:
  - Inicio: resumen y movimientos recientes.
  - Ingresos: formulario deshabilitado + tabla de ejemplo.
  - Egresos: formulario deshabilitado + tabla de ejemplo.
  - Reportes: filtros deshabilitados + kpis y distribución por categoría.
- Tema visual inspirado en cuero (tonos marrones/cálidos).

## Ejecutar (desarrollo)
1. Instala dependencias.
2. Levanta el servidor de desarrollo.

```powershell
npm install
npm run dev
```

Luego abre la URL que te muestre (por defecto http://localhost:5173).

## Construir
```powershell
npm run build
npm run preview
```

> Nota: Es solo una maqueta visual. Los formularios y botones están deshabilitados a propósito.
